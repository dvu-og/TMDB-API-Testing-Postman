# TMDB API Testing Using Postman

## Project Overview
This project focuses on testing The Movie Database (TMDB) REST APIs using Postman. The objective is to validate API responses, verify status codes, check response time, and ensure the accuracy of returned JSON data.

## Tools and Technologies
- Postman
- JavaScript
- REST API
- JSON
- TMDB API

## APIs Tested
1. Popular Movies
2. Upcoming Movies
3. Top Rated Movies
4. Movie Details
5. Search Movies
6. Movie Genres

## Testing Performed
- HTTP status code validation
- Response time validation
- JSON response validation
- Movie results validation
- Movie title validation
- Movie ID validation

## Authentication
Bearer Token authentication was used to access the TMDB API.

## Project Status
Completed initial API functionality testing and basic response validation.

## Learning Outcomes
- Understanding REST API testing.
- Working with GET requests.
- Understanding API authentication.
- Writing JavaScript test scripts in Postman.
- Validating API responses.
